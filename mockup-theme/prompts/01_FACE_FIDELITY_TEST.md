# 01 — Face Sticker Fidelity Test

Reference Lock이 확인된 같은 대화에서 실행한다.

```text
REAL PRODUCT FIDELITY TEST — FACE STICKER를 생성하라.

출력:
- 세로형 4:5
- 완전한 탑뷰
- pale cool blue-gray 배경
- 5000~5600K 중성 스튜디오 주광
- 우드, 노란 조명, 추가 소품 없음

오른쪽:
- REF_FACE_SHEET_01의 실제 A5 Face Sticker 시트
- 화면 높이의 약 72~78%
- 프레임과 평행
- 완전한 판매 전 상태
- 4열 × 5행, 20개 스티커 유지
- 빈 구멍, 떼어진 스티커, 들린 모서리 없음
- 실제 헤더와 하단 영역을 임의로 다시 쓰지 않음

왼쪽:
- REF_FACE_SHEET_01과 동일한 실제 얼굴의 별도 완성 스티커 3개
- 위 0.75in / 19mm
- 가운데 1.25in / 32mm
- 아래 2.5in / 64mm
- 하나의 수직축과 동일한 시각적 간격
- 실제 크기 비율 유지

추가 물체를 넣지 마라. 하단 여백은 의도적으로 비운다.

제품 잠금:
- 동일한 얼굴, 눈, 코, 입, 표정, 머리카락, 피부색과 외곽선
- White Matte, 약 0.1mm의 얇은 비닐
- 균일한 흰색 칼선
- 얼굴을 다시 생성하거나 서로 다른 아기로 만들지 않음

생성 후 다음을 확인해 보고하라:
- 얼굴 동일성
- 4×5 배열
- 시트 완전성
- 세 크기의 실제 비율
- 텍스트·로고 영역 변형 여부
```
