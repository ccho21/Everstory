# 10 — Empty Style Stage

요청 JSON과 장면 카드를 먼저 대화에 제공한 뒤 실행한다.

```text
STYLE APPLICATION — PASS A: EMPTY STAGE를 생성하라.

입력된 MOCKUP_REQUEST와 SCENE_CARD를 따른다. 이전 대화의 Reference Lock과 Product Hard Lock은 유지하지만, 이번 단계에서는 실제 시트, 실제 스티커, 임시 아트워크, 브랜드 로고와 제품 문구를 넣지 않는다.

목적:
실제 제품을 다음 편집에서 정확히 삽입할 수 있도록 배경, 소품, 카메라, 조명, 재질과 빈 부착면만 승인받는다.

필수:
- SCENE_CARD의 카메라와 정렬 규칙
- 요청된 화면비
- 장면별 컬러 레시피
- 실제 크기에 충분한 빈 부착면
- 모든 제품의 현실적인 크기 관계
- 5000~5600K 중성 주광
- 실제 재질과 얇은 접촉 그림자

금지:
- 가짜 스티커 또는 임시 캐릭터
- 가짜 A5 제품 시트
- 가짜 로고와 읽을 수 없는 문구
- 우드 테이블, 원목 소품, 노란 조명
- 의미 없는 컬러 스트립과 장식 오브제
- 장면 카드를 벗어난 추가 제품

지금은 빈 스타일 무대 한 장만 생성하고 기다려라. 제품을 삽입하지 마라.
```
