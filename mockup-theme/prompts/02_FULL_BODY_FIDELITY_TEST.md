# 02 — Full Body Sticker Fidelity Test

Reference Lock이 확인된 같은 대화에서 실행한다.

```text
REAL PRODUCT FIDELITY TEST — FULL BODY STICKER를 새로운 이미지로 생성하라.

출력:
- 세로형 4:5
- 완전한 탑뷰
- pale cool gray 배경
- 5000~5600K 중성 스튜디오 주광
- 우드, 노란 조명, 릴리스 라이너 없음

오른쪽:
- REF_FULL_BODY_SHEET_01의 실제 A5 시트
- 프레임과 평행
- 5열 × 4행, 20개 위치 유지
- 모든 스티커가 있는 완전한 판매 전 상태
- 아이의 얼굴, 몸, 손, 발, 파란 옷과 포즈 보존

왼쪽 위:
- REF_FULL_BODY_SHEET_01과 동일한 1.5in / 38mm 완성 전신 스티커 1개

왼쪽 아래:
- muted coral의 큰 태그형 키링
- 링 아래에 최소 3.25 × 3.25in의 평평한 태그 플레이트
- 태그 중앙에 동일한 1.5in 전신 스티커 부착
- 스티커는 태그 표면에 완전히 밀착

제품 잠금:
- 전신을 자르지 않음
- 얼굴, 포즈, 의상, 신체 비율을 다시 생성하지 않음
- White Matte, 약 0.1mm의 얇은 비닐
- 균일한 흰색 칼선

생성 후 얼굴·전신 동일성, 5×4 배열, 실제 크기와 태그 밀착을 확인해 보고하라.
```
