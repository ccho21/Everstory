# Everstory Mockup Theme Bible

## 1. 한 문장 정의

Everstory 목업은 실제 스티커를 정확하게 보존한 상태에서, 서로 다른 재질의 제품들이 계산된 축과 간격으로 정렬되고, 중성 주광과 현대적인 컬러로 촬영된 프리미엄 카탈로그 이미지다.

## 2. 시각적 우선순위

1. 실제 제품 정확도
2. 스티커 크기와 부착 물리
3. 정렬과 간격
4. 제품이 잘 보이는 명확한 용도
5. 장면별 컬러와 재질
6. 분위기와 장식

분위기를 위해 제품을 바꾸지 않는다. 구도를 채우기 위해 의미 없는 물체를 넣지 않는다.

## 3. 제품 Hard Lock

실제 제품 자료가 제공되면 다음을 변경하지 않는다.

- 얼굴과 인물 정체성
- 표정, 눈, 코, 입, 머리카락과 피부색
- 전신 포즈, 손, 발, 의상과 신체 비율
- shape sticker의 원래 외곽선
- 흰색 커팅 테두리와 제품 종횡비
- A5 시트의 실제 배열과 스티커 개수
- 확인된 헤더·푸터·로고·QR 영역

실제 시트는 새로 그릴 참고 이미지가 아니라 삽입할 평면 제품 자산으로 취급한다.

## 4. 스티커 물리

- 기본 재질: `White Matte`
- 약 0.1mm의 얇은 비닐
- 균일한 1~2mm 흰색 다이컷 테두리
- 부착된 스티커는 표면에 완전히 밀착
- 곡면에서는 표면 곡률을 자연스럽게 따름
- 부착된 가장자리 아래에 두꺼운 그림자가 없음
- 느슨하게 놓인 스티커에만 매우 얇은 접촉 그림자 허용
- 폼, 판지, 자석, 에나멜 핀 또는 두꺼운 배지처럼 표현 금지

크기는 주변 물체와 실제 비율을 유지한다.

| 인치 | 밀리미터 | 주 사용면 |
|---:|---:|---|
| 0.75 | 19 | 작은 휴대용 배터리, 휴대폰 하단, 작은 태그 |
| 1.00 | 25 | 휴대폰, 작은 케이스, 공책 |
| 1.25 | 32 | 공책, 휴대폰, 필통, 텀블러 |
| 1.50 | 38 | 태그, 필통, 태블릿, 텀블러 |
| 2.00 | 51 | 앨범, 큰 케이스, 노트북, 텀블러 |
| 2.50 | 64 | 큰 태그, 노트북, 태블릿, 넓은 케이스 |

## 5. 구성

- 완전한 탑뷰 또는 원근 왜곡이 적은 정면·3/4 시점
- 제품 가장자리는 프레임과 평행하거나 모두 하나의 공통 각도를 따름
- 동일 그룹의 간격은 시각적으로 동일
- 무작위 회전, 캐주얼한 흩뿌림, 의미 없는 대각선 금지
- 제품끼리 불필요하게 겹치지 않음
- 실제 부착 면을 다른 소품으로 가리지 않음
- 정렬은 정밀하지만 재질에는 현실적인 미세 변화가 있음

`S01_SHEET`에서는 오른쪽 A5 시트와 왼쪽 개별 스티커만 사용한다. 하단을 채우기 위한 카드, 릴리스 라이너, 컬러 스트립 또는 장식 막대를 넣지 않는다. 시트는 완전한 판매 전 상태이며 빈 다이컷 구멍이 없다.

## 6. 컬러

핵심 팔레트:

- Soft Neutral Gray `#D2D0CD`
- Deep Teal `#295E61`
- Blue-gray `#536873`
- Warm Off-white `#F8F0EA`
- Dark Stone `#595858`
- Warm Cream `#E7E1C5`

확장 팔레트:

- Muted Coral `#C9786A`
- Controlled Cobalt `#4F6F9C`
- Sage `#8FA38C`
- Smoky Lavender `#938BA4`
- Muted Saffron `#D3AD4A`

각 장면은 3~4개 색을 사용하되 모든 장면에 같은 조합을 반복하지 않는다. 색은 실제 제품과 표면의 면색으로 사용한다. 화면 전체를 덮는 노란색, 베이지색 또는 주황색 컬러 캐스트로 사용하지 않는다.

## 7. 조명과 재질

- 5000~5600K 중성 주광
- 흰색은 흰색, 회색은 중성 회색으로 보이는 화이트 밸런스
- 얇고 물리적으로 일관된 접촉 그림자
- 실제 종이, 패브릭, 실리콘, 금속, 유리 질감
- 필요에 따라 부드러운 확산광 또는 중성의 선명한 측면광

금지:

- 골든아워와 노란 전구
- 우드 테이블, 나무 장난감, 원목 블록
- 라탄, 대나무, 우드 비즈
- 베이지색 소품만 반복하는 구성
- 점토 같은 CGI 표면
- 과도한 HDR, 블룸, 헤이즈, 빈티지 필터
- 비현실적으로 둥근 추상 소품

## 8. 장면별 고정 사항

### S01 Sheet

- 오른쪽: 완전한 A5 시트
- 왼쪽: 동일 제품의 개별 스티커
- 추가 소품 없음
- 시트에서 스티커를 떼어내지 않음

### S02 Stationery

- 패브릭 공책은 하나만 사용
- 정확한 A5 시트
- 두 번째 책이나 앨범 대신 무광 금속 필통 또는 단단한 소품 케이스
- 링보다 넓은 태그 플레이트가 중요한 대형 키링
- 각 제품은 서로 다른 재질과 용도를 가짐

### S03 Tech

- 실제 기기 사진 필수
- 공급된 Apple 로고와 기기 디테일을 가리지 않음
- AirPods는 기본 부착 제품에서 제외
- 작은 부착면은 MagSafe 보조배터리 또는 휴대용 SSD 사용
- 모든 기기에 스티커를 붙이지 않고 1~2개만 선택
- 밝은 문구 장면과 구별되는 그래파이트·블루 계열 무대

### L01 Lifestyle

- 손, 팔, 얼굴 없음
- 스티커가 이미 부착된 제품이 주인공
- 배경은 산책로, 여행, 사무실, 현대적 야외 공간 등 상황에 따라 변경 가능
- 배경이 바뀌어도 제품 선명도, 중성 주광, 스티커 크기와 물리는 유지

## 9. 레퍼런스 독창성

외부 스타일 레퍼런스에서는 구도·조명·여백 같은 추상 원칙만 추출한다. 동일한 물체 수, 위치, 카메라, 그림자, 배경색 조합을 복제하지 않는다. 실제 Everstory 제품 자료는 스타일 레퍼런스가 아니라 제품 사실 자료다.

## 10. 승인 기준

- 빈 무대 승인과 제품 삽입 승인은 별도다.
- 실제 얼굴·시트·텍스트가 변한 생성 결과는 미감이 좋아도 최종 승인하지 않는다.
- 최종 상업용 이미지는 실제 PNG 후합성을 허용하며, 제품 정확도 측면에서는 이를 우선한다.
