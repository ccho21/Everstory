Design System

v1.1 · ROUND 2 · 2026-07-22 · 라이브 Horizon 테마 감사 기반 · 웹 스토어 전용 (인쇄 .ait 팔레트는 별도 유지) · §1·§8 승인 완료, 테마 사본 적용됨

0 · 디자인 원칙

모든 세부 결정은 이 세 문장에서 나온다. 판단이 어려울 때 여기로 돌아올 것.

① 사진이 컬러다 (The photo is the color)

everstory 의 상품은 고객의 컬러풀한 사진 누끼 스티커다. UI 가 색을 가지면 상품과 경쟁한다. 따라서 UI 는 잉크(검정)와 종이(흰색·웜 뉴트럴)만 사용하고, 화면에서 유일하게 채도가 있는 것은 항상 상품 사진이어야 한다.

② 종이의 감각 (Paper, not glass)

스티커는 종이 물성의 제품이다. 웹도 같은 물성을 따른다 — 그림자·글로시·그라데이션 대신 헤어라인 보더, 미세한 웜톤 배경, 평평한 면. "매트한 인쇄물" 느낌이 기준.

③ 직선의 UI, 곡선의 상품 (Straight frame, curvy product)

누끼 스티커의 외곽선은 유기적인 곡선이다. UI 프레임이 각질수록(버튼 radius 0, 정직한 그리드) 상품의 곡선이 도드라진다. 라운딩은 위계다: CTA = 0 · 그릇(카드·인풋) = 4px · 라벨(배지) = pill. 이 세 단계 외의 radius 값을 만들지 않는다.

현재 라이브 테마 평가: 버튼 0 / 카드·인풋 4 / 배지 pill — 이미 이 원칙과 일치한다. 우연이었더라도 올바른 선택이므로 유지하고, 이제부터는 근거를 알고 쓰는 것.

왜 웜 그레이인가: #F5F5F5 는 무채색 중립이라 "디지털 기본값" 인상을 준다. #F7F5F2 는 같은 밝기에서 약간의 황미(黃味)를 더해 스티커 뒷대지(backing paper)·크라프트지의 온도를 만든다. 사진 속 아기·가족의 웜톤 피부와도 충돌하지 않는다.

왜 하늘색 폐기인가: scheme-4 (#E1EDF5) 는 팔레트에서 유일한 한색(寒色)으로, 원칙 ① "사진이 컬러다"를 깨는 배경색이다. 세이지(#EEF1EA)는 종이·식물 계열 뉴트럴이라 유지 가능하지만, 파우더 블루는 명백한 "색"이므로 배경으로 쓰지 않는다.

왜 Blush 가 아니라 Clay 인가 (사용자 피드백 반영): 캔디 파스텔 핑크는 AI 생성물 특유의 달콤한 톤이다. Clay 는 채도를 낮춘 흙빛 로즈로, 크라프트지·리소그래프 인쇄 계열이라 "디지털이 아니라 인쇄물"로 읽힌다. 또 고객 사진은 대부분 채도가 높은데(쨍한 원색 옷·장난감), 저채도 웜톤인 Clay 는 그 옆에서 경쟁하지 않고 물러나 사진을 받쳐 준다. 피부톤과 같은 웜 계열이라 얼굴 사진과도 충돌 없음. 검정 텍스트 대비 ≈ 9.8:1 (AA 통과).

사용 규칙 유지: Clay 는 배지("Sale" 등)에만. 버튼·링크·아이콘에 쓰는 순간 팔레트가 무너진다.

사용 규칙

Do

  • Bayon 은 7단어 이하의 짧은 제목에만
  • H1 만 uppercase, H2 이하는 sentence case (라이브 설정과 동일)
  • 가격·숫자·긴 문장은 항상 Inter
  • 본문 줄 길이 56–68ch 유지
  • Eyebrow(12px caps) → H1 → 본문 순서의 위계를 히어로마다 반복 — 이미 라이브에 있는 좋은 패턴

Don't

  • Bayon 으로 가격·숫자 표기 금지 — Bayon 숫자는 인장(印章)처럼 보여 상거래 신뢰를 깎는다
  • Bayon 을 12–20px 소형 사이즈로 쓰지 않는다 (18px 미만 가독성 급락)
  • Inter Bold(700)를 본문 강조 이외에 남용하지 않는다
  • 새 폰트 추가 금지 — 두 서체로 부족한 경우는 없다

5 · 아이코노그래피

시스템 하나만 쓴다: 스트로크 1.5px 라인 아이콘. 채움(filled)·이모지·일러스트 아이콘 금지.

search · cart · account · shipping · keepsake — 전부 1.5px stroke, currentColor
규칙스펙
소스Lucide (lucide.dev, ISC 라이선스 무료). Horizon 내장 아이콘과 같은 라인 계열이라 섞여도 이질감 없음
스트로크1.5px 고정 · stroke-linecap: round
사이즈nav 유틸리티 24px · 인라인(트러스트 스트립 등) 20px
색currentColor 만 — 아이콘에 별도 색 지정 금지 (원칙 ①)
개수 제한사이트 전체에서 10종 이하. 아이콘이 많다는 건 텍스트로 할 말을 아이콘에 떠넘겼다는 뜻
"handmade 인데 손그림 아이콘 쓰면 안 되나?" — 안 쓴다. 손맛(handmade)은 상품 사진 속에서 보여주는 것 (가위, 손, 시트 질감). UI 아이콘까지 손그림이면 사이트가 공예품 흉내를 내는 것이고, 정제된 UI 위의 진짜 수공 상품이라는 대비가 사라진다.

6 · 사진 & 이미지 아트디렉션

이 사이트에서 가장 중요한 섹션. UI 는 조연, 사진이 주연이다. photo_shotlist.md 와 연계.

촬영 공식 (모든 상품 사진 공통)

항목스펙
배경웜 뉴트럴 실물 — 크라프트지, 린넨, 웜 그레이 도화지. 순백 배경 금지 (흰 시트가 뜬다)
조명창가 자연광 + 반사판. 그림자는 부드럽게 살린다 — 그림자가 있어야 시트가 "물건"으로 보인다
필수 컷 4종① 시트 전체 flat lay (정면) ② 45° 앵글 + 손 (스케일 큐) ③ 흰 테두리·칼선 클로즈업 ④ 사용 맥락 (물병·노트북·다이어리에 붙인 컷)
흰 테두리누끼 스티커의 흰 아웃라인이 곧 상품이다. 클로즈업에서 테두리 두께와 칼선이 또렷이 보여야 "직접 딴 누끼"라는 증거가 된다
색보정웜 화이트밸런스 + 채도 약간 절제 (파스텔 유지). 필터·비네팅 금지

히어로 이미지 — 가장 시급한 개선

현재 히어로의 문제: 지금 라이브 히어로는 스티커 "시안 그래픽"(합성 이미지)처럼 보인다. 커스텀 수공 제품에서 이는 신뢰 문제다 — 고객은 "내가 받을 실물"을 보고 싶어 한다. 실물 시트를 실제로 출력·촬영한 사진으로 교체하는 것이 이 디자인 시스템 전체에서 가장 전환율 효과가 큰 단일 작업이다.

Do

  • 실물 출력 시트 + 자연광 촬영
  • 손·가위·핀셋 등 제작 도구가 걸친 컷 (by-hand 증거)
  • 4:5 세로비 기본 (카드·PDP 일관)
  • 한 페이지의 사진들은 같은 배경 톤으로 통일

Don't

  • AI 생성·합성 티가 나는 이미지 — 커스텀 상품 신뢰의 최대 적
  • 스톡 사진 (남의 가족 사진은 이 브랜드에서 즉시 이질감)
  • 순백 배경 + 그림자 제거 (전자제품 쇼핑몰 문법)
  • 비율 제각각 썸네일 혼용
