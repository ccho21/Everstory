# 한국어 Footer 카피

영어 페이지 끝에 한국어 요약을 추가할 때 사용하는 copy SOT. 영어 원문이 기준이고, 한국어 footer는 한국어 고객이 핵심 조건을 빠르게 확인하도록 돕는 요약이다.

## FAQ — 한국어 footer

```
한국어 자주 묻는 질문

Q. 주문은 어떻게 진행되나요?
A. 상품을 선택하고, 비-Package 상품은 사이즈 / 재질 / Photos to include를 선택합니다. Package 상품은 Big / Medium / Small print 구역별로 후보 사진을 업로드합니다.

Q. Photos to include는 무엇인가요?
A. 서로 다른 사진을 몇 장 넣을지 의미합니다. 스티커 총 개수는 사이즈와 사진 비율에 따라 달라집니다.

Q. 한국어로 주문 가능한가요?
A. 네. 주문 노트 또는 이메일로 한국어 소통 가능합니다.

Q. 사진이 부족하거나 흐리면 어떻게 되나요?
A. 제작이 어려운 사진이 있거나 Package tier별 필요한 장수를 채우기 어렵다면 인쇄 전에 이메일로 안내드립니다.

Q. 사이즈는 어떻게 고르나요?
A. 가장 무난한 크기는 1" / 25mm입니다. Full Body Sticker는 1.25" / 32mm 이상을 권장합니다.

Q. 어린이가 사용해도 되나요?
A. 본 제품은 장식용 사진 스티커이며 장난감 또는 어린이용 제품이 아닙니다. 만 3세 미만 영유아에게는 적합하지 않으며 (질식 위험), 만 14세 미만 어린이가 사용할 때는 보호자가 부착하거나 감독해주세요. 사진 속 인물이 어린이여도 완성된 시트는 보호자가 다루는 것을 전제로 합니다. 영유아 손이 닿지 않는 곳에 보관해주세요.

문의: studio.everstory@gmail.com
```
