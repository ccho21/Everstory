# 한국어 Footer 카피

영어 페이지 끝에 한국어 요약을 추가할 때 사용하는 copy SOT. 영어 원문이 기준이고, 한국어 footer 는 한국어 고객이 핵심 조건을 빠르게 확인하도록 돕는 요약이다.

각 영어 페이지 마지막에 다음 형식으로 추가:

```html
<hr>
<h3>한국어 안내</h3>
[아래 카피]
```

또는 Shopify Rich Text 의 horizontal rule + Heading 3.

톤: `docs/design/brand.md` voice 와 일치 — 에디토리얼 / 부티크 / 럭셔리. 친근하지만 가볍지 않게.

## 6. FAQ — 한국어 footer

FAQ 영어 본문 마지막 (Q. Do you make stickers other than photos?) 직후에 추가. 핵심 7개 Q&A 만:

```
한국어 자주 묻는 질문

Q. 주문은 어떻게 진행되나요?
A. 상품 (Solo / Duo / Trio / Memory Pack) 과 사이즈, 재질을 선택하고 결제 시 사진과 함께 주문 노트에 원하는 디테일 (특정 얼굴 크롭 금지 / 선호 톤 / 강조 부분 등) 을 적어주세요. 1영업일 안에 작업을 시작해서 2–5영업일 안에 배송됩니다.

Q. 한국어로 주문 가능한가요?
A. 결제는 영어로 진행되지만, 주문 노트에 한국어로 디테일 적어주시거나 이메일로 한국어 회신 주시면 한국어로 응대합니다. 사진 교체 요청, 픽업 안내 모두 한국어 가능합니다.

Q. 한국으로 배송되나요?
A. 현재는 캐나다 온타리오주 내에서만 배송됩니다. 한국 또는 미국 발송이 필요한 경우 이메일로 별도 문의 주세요. 케이스별로 검토합니다.

Q. 토론토에서 직접 픽업할 수 있나요?
A. 네, 가능합니다. 결제 시 "Toronto Studio Pickup" 선택. 준비 완료 시 이메일로 안내드립니다.

Q. 사진은 어떤 것이 좋은가요?
A. 밝은 자연광, 피사체가 화면을 가득 채우고, 흔들림이 적은 사진이 좋습니다. 배경 제거와 색감 보정은 저희가 진행합니다.

Q. 환불은 어떻게 되나요?
A. 인쇄 시작 전까지 (보통 주문 후 1영업일 이내) 전액 환불 가능합니다. 인쇄 결함은 100% 무상 재제작, 배송 분실 (14영업일 미수령) 도 1회 무상 재제작 진행합니다.

Q. 사이즈는 어떻게 선택하나요?
A. S (1인치, 25mm) 가 가장 인기 있습니다. 다이어리·플래너·텀블러·핸드폰 케이스에 무난합니다. M (1.25") 은 노트북·텀블러, L (1.5") 은 큰 텀블러·차량용에 좋습니다. 고민되시면 S 추천.

문의: [orders@everstory-domain.com] (한국어 답변 가능)
```

```

1. 사이즈와 재질 선택
2. 사진 업로드 + 이름(또는 반려동물 이름) 입력 + 원하는 디테일 (특정 얼굴 크롭 금지 / 선호 톤 / 강조 부분 등) 을 노트에 적기

4. 2–5영업일 안에 인쇄·컷팅·발송 (인쇄 시작 전 전액 환불 가능)

토론토 스튜디오 픽업 가능. 자세한 내용은 FAQ 또는 [orders@everstory-domain.com] 문의.
```

## Shopify 어드민 등록 시 주의

- 한국어 카피는 영어 페이지 본문 끝에 동일 페이지 안에 추가 (별도 페이지 아님)
- Shopify Rich Text Editor 의 Heading 3 사용 → "한국어 안내" 헤더는 영어 컨텐츠와 시각적 구분
- horizontal rule (`<hr>`) 로 영어 / 한국어 구분
- footer 의 "Contact" 이메일 주소는 영어와 동일한 placeholder `[orders@everstory-domain.com]` — 도메인 확정 후 일괄 교체
