Storefront wireframe set

12 pages, structural-only. Component labels follow Shopify Horizon section/block names so the wireframe can be mapped 1:1 in the theme editor. Design (typography, color, real images) is intentionally absent.

Product model — 5 SKUs across 2 PDP archetypes: Non-Package (Face / Full Body / Shape Sticker — Size · Material · Photos to include) and Package (Package Mini / Full — Material only, Big/Medium/Small tier upload). Sizes are inch/mm only. product-face-sticker.html and product-package-mini.html are the two shared templates; the 5 live products reuse them.
Horizon coverage — 15 of 18 components are no-code in Horizon's editor. 3 items need extra work and are marked ⚠ NEEDS APP/CODE on the relevant page: product photo upload (Easify Product Options app or custom Liquid), KakaoTalk social icon (custom snippet), policy side-nav (dropped — accordion-only).

Header utility policy

The header shows three utility icons across all pages — search (⌕), account (☺), and cart (🛒). No language toggle: Everstory ships English-only with a Korean helper section embedded in each page body.
  • Search — Horizon's built-in predictive-search drawer. No separate search-results wireframe; uses Horizon's default search.json template.
  • Account — Horizon's default customer/login, customer/register, customer/account templates. No custom wireframe; checkout supports guest as well.
  • Language — no toggle. English single-locale. Korean copy lives inline as a "한국어 안내" block on each page.
