Everstory · Brand Exploration · Logo Concepts

Primary system pushed beyond the luxury wordmark

A working board of logo comps for Everstory — the Toronto studio that hand-traces photographs into A5 die-cut sticker sheets. The current identity leans editorial-luxury (a Didone wordmark). This set deliberately leaves that lane and explores friendlier, more modern, and more product-true territory while keeping the locked name, palette, and tagline.

What we're moving away from

EVERSTORY STUDIO

High-contrast Didone serif · fashion-magazine luxury · thin stem / thick bowl. Beautiful but generic in the "premium serif" lane, and cold for a pet/kid/family memory product.

What stays locked

SPEC 1

The locked device

notch + kiss-cut + coral tick
EVERSTORYSTUDIO · BY HAND
canonical primary lockup — this SVG path IS the spec
Notch geometryCorner cut begins at ~92% of width along the top edge, diagonal down to ~22% of height on the right edge. Sharp — corner radius 0. (The −12% "recommended" depth from ROUND 3; deeper reads coupon/ticket.) Canonical source = the path M8 8 H308 L332 30 V108 H8 Z on a 340×116 box.
Kiss-cut linestroke-dasharray: 9 3.5 · stroke-width: 1.25 · linecap: butt · opacity .92. Designed rhythm — not a CSS default. Stroke uses the lockup ink (adapts on inverse).
Coral tickOne short registration tick at the inner notch corner, coral #FBAAA8 — the only colour break in the mark. Optional; drops cleanly in 1-colour.
Production tieThe dashed line maps to the real CutContour spot (M100 · SPOT, Summa D75). The logo's signature = the actual kiss-cut, so it must reproduce as a single spot path — no gradient, no raster.
