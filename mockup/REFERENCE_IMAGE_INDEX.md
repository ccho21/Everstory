## How to Photograph the First Product Reference

The most useful first upload is one high-resolution A5 sheet photograph:

- camera directly above the sheet,
- all four corners visible,
- no hand or prop overlap,
- no strong perspective,
- soft neutral daylight,
- no filter,
- no portrait mode blur,
- no patterned shadow,
- highest available resolution,
- original file preserved.

This image becomes the main source for replacing provisional sheets inside approved concept scenes.

## Multi-image Input Labels

When attaching multiple images, identify them explicitly:

```text
Image 1 — Actual product source:
Preserve exact sticker artwork, count, layout, cut shape, header, and material.

Image 2 — Golden Style reference:
Use only the background, lighting, camera angle, and composition.

Image 3 — Optional prop reference:
Use only the prop type and approximate position.
```

Do not say only “use these as reference.” Assign a role and a preserve rule to each image.
