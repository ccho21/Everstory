## 공통 구조

색 채움 → 키라인 → 흰 오프셋(칼선 여백)의 3층. 알파벳 두 장은 검정 키라인, 두들 시트는 진녹 키라인. `Everstory_alphabet.jsx`(검정 키라인) · `Everstory_with_name.jsx`(레이어드 = 배경 윤곽 칼선) 구조와 같다.

## 팔레트 실측

posterize 5bit 상위 9색, 오차 ±4/채널. 상위권 밖 색(두들 시트의 빨강·핑크·하늘 등)은 미측정.

## 제작 시 주의

AI 생성물이라 글자마다 획 두께·모서리가 미세하게 다르고, 이름 시트에 오타(Chirstopher)가 있다. 트레이스로 옮기면 그 불일치까지 복제된다 → 서체 기반 재구성 권장 (2026-09-10 분석: 픽셀 100% 불가, 인쇄 기준 99%+).
